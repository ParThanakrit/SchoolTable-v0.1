# SchoolTable — หน้าบ้านฉบับปรับปรุง

เปิด `schooltable.html` เพื่อทดลอง ใช้ได้จากไฟล์โดยตรงและผ่านเว็บเซิร์ฟเวอร์ เก็บโฟลเดอร์ `css` และ `js` ไว้ด้วยกัน

## ระบบดีไซน์ใหม่ (UX/UI)

แนวคิด: **"หลากสีแบบทางการ"** — ใช้สีแบรนด์คราม(Indigo) เป็นแกน แล้วเพิ่มชุดสีประจำหมวดอย่างเป็นระบบ
เพื่อให้ดูมีสีสัน น่าสนใจ และมีเอกลักษณ์ แต่ยังสุขุมและเป็นทางการ

- ไฟล์หลักของดีไซน์คือ `css/theme.css` — โหลดต่อจาก `app.css → print.css → ux.css` จึงเป็น
  "แหล่งความจริงเดียว" ของสี ตัวอักษร เงา และรูปทรงบนหน้าจอ (ครอบด้วย `@media screen`
  ทั้งไฟล์ จึงไม่กระทบเอกสารพิมพ์ A4 ที่ยังเป็นขาว–ดำเสมอ)
- โทเคนสีอยู่ที่ `:root` (ธีมสว่าง) และ `:root[data-theme="dark"]` (ธีมมืด) ใน `theme.css`
  ปรับสีแบรนด์ทั้งระบบได้ที่ตัวแปร `--brand`, `--brand-gradient` และชุดสีประจำหมวด `--c1`…`--c6`
  (โทเคนเดิม `--primary`, `--info`, `--success`, ฯลฯ ยังใช้ชื่อเดิม จึงไม่ต้องแก้ทุกหน้า)
- ฟอนต์: หัวข้อ/แบรนด์ใช้ **Kanit**, เนื้อหา/ตารางใช้ **IBM Plex Sans Thai** (โหลดจาก Google Fonts
  ที่ `<head>` ของ `schooltable.html`) ถ้าเปิดแบบออฟไลน์จะถอยไปใช้ฟอนต์ในเครื่องอัตโนมัติ
  (`Noto Sans Thai` / `Leelawadee UI` / `Tahoma`) — แก้สแตกฟอนต์ได้ที่ `--font-sans`, `--font-display`
- ไอคอน: ชุด SVG แบบเส้นอยู่ใน `js/ux.js` (ออบเจกต์ `paths` + ฟังก์ชัน `icon(name)`)
  เมนูด้านซ้ายใน `js/app.js` อ้างชื่อไอคอนผ่านฟิลด์ `icon` ของแต่ละรายการ และมี `phase` (1–3)
  สำหรับสีประจำขั้นตอน (แสดงเป็นตัวเลขวงกลมและแถบสีของเมนูที่กำลังเปิด)
- ตารางสอน: แต่ละคาบส่งสีประจำกลุ่มสาระผ่านตัวแปร `--subject-color` (ดู `js/pages/timetable.js`)
  แล้ว `theme.css` นำไปทำพื้นหลังอ่อน ๆ ด้วย `color-mix` ทำให้กวาดสายตาหาวิชาได้เร็ว
  (เบราว์เซอร์เก่าที่ไม่รองรับ `color-mix` จะเห็นเป็นเส้นขอบสีด้านซ้ายเหมือนเดิม)
- การ์ดสถิติหน้าภาพรวมมีไอคอนและสีประจำการ์ด (`stat--c1`…`stat--c4`) กำหนดใน `js/pages/overview.js`

## อัปเดตรอบล่าสุด (ปรับตามที่ผู้ใช้ขอ)

- **ตั้งค่าพักเบรกได้หลายช่วง** — หน้าตั้งค่าโรงเรียน > ผังคาบเรียน มีปุ่ม “จัดการคาบพัก” รายวัน
  เพิ่มคาบพักได้หลายช่วง (เช่น พักเช้า พักกลางวัน) ตั้งชื่อและความยาว (นาที) ของแต่ละช่วงได้เอง
  โครงสร้างข้อมูลยังเป็น `periods[]` เดิม (`isBreak`,`label`) · ตัวสร้างผังคือ `store.buildDayPeriods(count, breaks, start, teachLen)`
  โดย `breaks` เป็น `{ periodNo: {label, minutes} }` (ยังรองรับพารามิเตอร์แบบเดิมที่เป็นเลขคาบพักเดียว)
- **ตัด “ประเภทห้อง” ออกทั้งระบบ** — หน้าอาคารและห้อง, หน้ารายวิชา และตัวจัดตารางไม่ใช้ประเภทห้องอีกต่อไป
  ห้องใดก็ใช้กับวิชาใดก็ได้ (ยังยึดห้องที่เลือกไว้ต่อรายการในหน้าจัดครูผู้สอน = `assignment.roomId`)
  ฟิลด์ `roomTypeId`/`requiredRoomTypeId` เดิมในข้อมูลถูกปล่อยไว้เฉย ๆ ไม่แสดงและไม่ถูกใช้ จึงเปิดไฟล์สำรองเดิมได้ปกติ
- **หน้าอาคารและห้องแบบใหม่** — ดูห้องทั้งหมดในตารางเดียว กรองตามอาคาร + ค้นหาชื่อ · จัดการอาคารเป็นชิปแนวนอน
- **หน้ารายวิชา** — ตัดช่อง “ประเภทห้องที่ต้องใช้” และ “สีประจำวิชา” ออก · สีจุด/สีในตารางสอนยึดจาก **สีกลุ่มสาระ** แทน
- **หน้าจัดครูผู้สอน** — เปลี่ยนกล่องชั้นเรียนด้านซ้ายเป็น **แถบเลือกชั้นเรียนแนวนอน** (เลื่อนแนวนอน) ตารางจัดครูกว้างเต็มพื้นที่
- **สีสันสดใสขึ้น** — ปรับชุดสี `--c1`…`--c6` และสถานะให้สดขึ้น และเพิ่มความเข้มของพื้นหลังคาบในตารางสอน (ผ่าน `color-mix`)

## ชุดสีใหม่ (รอบล่าสุด)

- ปรับโทเคนสีทั้งชุดใน `css/theme.css` ให้สดใสขึ้นทั้งธีมสว่างและธีมมืด
  (แบรนด์ครามสด `--brand: #5b50ef`, ชุดสีหมวด `--c1…--c6`, พื้นหลังอมครามอ่อน, เงาอมคราม)
- **สีตัวอักษรสถานะผ่านค่าความต่างสี WCAG AA ทุกคู่** — ตรวจแล้วได้ 4.67–5.05 (สว่าง) และ 6.1–9.3 (มืด)
  หลักการคือ ใช้ `--c1…--c6` ที่สดจัดกับงาน "ตกแต่ง" (แถบสี ไอคอน การ์ด)
  ส่วน `--info/--success/--warning/--danger` คุมให้เข้มพอสำหรับเป็น "ตัวอักษร" บนพื้นอ่อนของตัวเอง
- สีประจำกลุ่มสาระในข้อมูลตัวอย่าง (`js/mockdata.js`) เปลี่ยนเป็นชุดสดใหม่ 9 สีที่แยกจากกันชัด
  ซึ่งเป็นสีที่ตารางสอนใช้แสดงผล
- มีตัวอัปเกรดสีอัตโนมัติใน `js/store.js` (`GROUP_COLOR_UPGRADE` ใน `mergeDefaults`)
  แปลงสีกลุ่มสาระ "ชุดค่าเริ่มต้นเดิม" ให้เป็นชุดใหม่เมื่อเปิดไฟล์ข้อมูลเก่า
  ถ้าผู้ใช้เคยตั้งสีเองไว้ จะไม่ถูกเปลี่ยน

## ปรับหน้าจอเพิ่มเติม (รอบก่อนหน้า)

- **อาคารและห้อง = กล่องเดียว** — การ์ดเดียวมีสวิตช์ `#rmView` สลับมุมมอง “ห้อง” / “อาคาร”
  (ตัวแปร `view` ใน `js/pages/rooms.js`) · มุมมองห้องมีตัวกรองอาคาร + ค้นหาชื่อ
  มุมมองอาคารเป็นตาราง มีปุ่ม “ดูห้อง” กระโดดไปกรองห้องของอาคารนั้นให้
- **หลักสูตร: ปุ่ม 3 กล่องสี่เหลี่ยมจัตุรัส** — คลาส `.row-actions--tiles` + `.tile-btn` (78×78px)
  เรียง 3 กล่องในแถวเดียว · เมนู “เพิ่มเติม” ยังเป็น `<details class="row-more">` เหมือนเดิม
  (เมื่อกางจะขยายเต็มความกว้างแล้วแสดงรายการด้านล่าง)
- **จัดครูผู้สอน: 1 วิชา = 1 บรรทัด** — แถวสูง ~56px (เดิม ~92px) · ชื่อวิชาอยู่ใน `.subj-cell` บรรทัดเดียว
  (กลุ่มสาระดูได้จากสีจุดและ tooltip) · ช่องครูเป็น `.teacher-cell` วางปุ่มเลือกครูกับชิป “+ ครูร่วม” ไว้บรรทัดเดียวกัน
  เมื่อกด “+ ครูร่วม” ค่อยขยายแถวลงมา (`.co-teacher[open]`)
- **ตารางสอนพอดีจอเดียว** — `table.timetable { min-width: 0 }` ทำให้ตารางย่อพอดีความกว้างที่มี
  ไม่ต้องเลื่อนซ้าย-ขวา (โหมด “กระชับ” ก็พอดีเช่นกัน ส่วนโหมด “ตัวอักษรใหญ่” ยังเลื่อนได้ตามตั้งใจ)
  และเอาการเลื่อนแนวตั้งในกล่องออก (`.tt-scroll { max-height: none }`)

## การใช้งานที่ปรับแล้ว

- เมนูเรียงเป็น เตรียมข้อมูล → กำหนดการสอน → จัดและตรวจตาราง พร้อมปุ่มยุบเมนูและปุ่มไปขั้นถัดไป
- หน้าแรกแสดงงานที่ยังค้าง ย่อข้อมูลที่เตรียมแล้ว และนำตารางล่าสุดขึ้นด้านบน
- หน้าจัดครูค้นหาด้วยชื่อ/กลุ่มสาระ แสดงภาระสอน กรองระดับชั้น เพิ่มครูร่วมเฉพาะแถว และแสดงสถานะบันทึก
- หน้าหลักสูตรรวมคำสั่งรองใน “เพิ่มเติม”
- หน้าเงื่อนไขย่อคำอธิบายและเตือนเมื่อออกจากหน้าโดยยังไม่ได้บันทึก
- หน้าจัดอัตโนมัติเลือกวิธีจัดได้หนึ่งแบบ แสดงผลล่าสุดด้านบน และแยกคาบค้างจากข้อเสนอปรับตาราง
- หน้าตารางเลือกขนาดและขยายพื้นที่ได้ คลิกดูรายละเอียด ลากย้ายพร้อมแสดงช่องที่วางได้ ย้อนกลับ/ทำซ้ำ และประกาศใช้ได้จากหน้านี้
- หน้าพิมพ์เลือกหน้าตัวอย่าง ซูม และแสดงจำนวนหน้าที่จะพิมพ์ เมื่อเลือกเฉพาะรายการแต่ยังไม่เลือกใคร ปุ่มพิมพ์จะถูกปิดไว้
- เรียงเลขชั้นเรียนตามธรรมชาติ เช่น ม.1/1, ม.1/2, …, ม.1/10

## ไฟล์สำหรับผู้พัฒนาที่รับงานต่อ

- `js/app.js`: เมนู การเปลี่ยนหน้า การเตือนข้อมูลที่ยังไม่บันทึก และการยุบแถบซ้าย
- `css/ux.css`: รูปแบบหน้าจอเพิ่มเติม สี ปุ่ม ตัวอักษร และการปรับตามขนาดจอ
- `js/ux.js`: ไอคอน SVG ช่องค้นหาครู และคำสั่งประกาศใช้ที่เรียกใช้ร่วมกัน
- `js/pages/`: หน้าจอและเหตุการณ์ของปุ่มแต่ละหน้า
- `js/store.js`: จุดจัดการข้อมูลเดิม ปัจจุบันยังบันทึกในเบราว์เซอร์ ข้อความสถานะจึงระบุว่า “ในเครื่องนี้”
- `js/printing.js` และ `css/print.css`: เอกสารพิมพ์จริง ส่วนซูม/เลือกหน้าตัวอย่างอยู่ใน `js/pages/print.js` และไม่เปลี่ยนขนาดเอกสารพิมพ์

ส่วนที่เพิ่มทำงานกับข้อมูลและตัวจัดตารางเดิม ยังไม่มีการเชื่อม API หรือบัญชีผู้ใช้ เมื่อเชื่อมการบันทึกกับเซิร์ฟเวอร์ ให้แสดง “บันทึกแล้ว” หลังได้รับผลสำเร็จจริง และคงสถานะผิดพลาดไว้เมื่อบันทึกไม่สำเร็จ

## ตรวจการทำงาน

ต้องมี Node.js และ Playwright พร้อมเบราว์เซอร์:

```text
node tests/engine-test.js
node tests/ux-test.js
```

ชุด UX ใช้ Microsoft Edge บน Windows และ Chromium บนระบบอื่น เปลี่ยนได้ด้วยตัวแปร `BROWSER_CHANNEL` ใช้ข้อมูลสมมติในบริบทเบราว์เซอร์แยก จึงไม่แตะข้อมูลที่ผู้ใช้กรอกไว้ในเบราว์เซอร์ปกติ

ทดสอบด้วยตนเองเพิ่มเติมได้โดยเลือกครู → จัดตาราง → ลากคาบ → ย้อนกลับ → ประกาศใช้ → เลือกพิมพ์หนึ่งรายการ แล้วดูว่าชื่อครู ชั้นเรียน และจำนวนหน้าตรงกัน

ชุด `acceptance*.js` เดิมอ้างอิงข้อความและโครงหน้าจอรุ่นก่อนปรับ จึงควรใช้ `ux-test.js` สำหรับหน้าจอชุดนี้
