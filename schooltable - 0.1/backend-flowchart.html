หน้าบ้านมีอยู่แล้ว

  • ฟอร์มและขั้นตอนเตรียมข้อมูล
  • scheduler.js และการตรวจเบื้องต้น
  • ลากแก้ ตาราง และตัวอย่างพิมพ์

หลังบ้านต้องทำ

  • บัญชี สมาชิก และ session
  • API ทุกหมวดพร้อม validation
  • revision/version, snapshot และ audit log

กติกาสำคัญ

  • school_id มาจาก session เท่านั้น
  • PUBLISHED แก้ย้อนหลังไม่ได้
  • ตรวจ H1–H9 ก่อน save/publish
เอกสารรายละเอียด API ตารางข้อมูล และกติกาอยู่ใน BACKEND-FLOWCHART.md
