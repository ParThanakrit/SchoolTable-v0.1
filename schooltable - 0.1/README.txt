SchoolTable — ระบบจัดตารางสอนอัตโนมัติสำหรับโรงเรียน
=====================================================

วิธีเปิดใช้งาน
--------------
1. แตกไฟล์ zip ออกมาให้ครบทั้งโฟลเดอร์
2. ดับเบิลคลิกไฟล์  schooltable.html   (แนะนำ Chrome, Edge, Firefox หรือ Safari รุ่นใหม่)
3. ใช้งานได้ทันที ไม่ต้องติดตั้งโปรแกรม ไม่ต้องมีเซิร์ฟเวอร์ และไม่มีหน้าล็อกอิน
   ระบบยังทำงานได้แม้ไม่ต่ออินเทอร์เน็ต แต่ฟอนต์เอกลักษณ์ (IBM Plex Sans Thai)
   จะโหลดจาก Google Fonts เมื่อเปิดครั้งแรก · ถ้าไม่มีเน็ต ระบบจะใช้ฟอนต์ในเครื่องแทน
   ให้อัตโนมัติ (Noto Sans Thai / Leelawadee UI / Tahoma) ทุกฟังก์ชันยังใช้ได้ครบ

สำคัญ: ต้องเก็บโฟลเดอร์ css/ และ js/ ไว้ข้าง ๆ ไฟล์ schooltable.html เสมอ
       ถ้าย้ายไฟล์ใดไฟล์หนึ่งออกไป ระบบจะทำงานไม่ครบ


ธีมสว่าง / ธีมมืด
-----------------
ปุ่มวงกลมครึ่งซีกบนแถบด้านบน (ซ้ายมือของปุ่มพิมพ์ตาราง) ใช้สลับธีม กดวนได้ 3 แบบ

  ◐  ตามเครื่อง   เปลี่ยนตามการตั้งค่าธีมของ Windows หรือ macOS ให้อัตโนมัติ (ค่าเริ่มต้น)
  ☀  สว่าง        บังคับให้เป็นธีมสว่างเสมอ ไม่สนใจการตั้งค่าของเครื่อง
  ☾  มืด          บังคับให้เป็นธีมมืดเสมอ

ระบบจะจำค่าที่เลือกไว้ให้ เปิดใหม่ครั้งหน้าก็ยังเป็นแบบเดิม
เอกสารที่สั่งพิมพ์จะเป็นกระดาษขาวตัวอักษรดำเสมอ ไม่ว่าหน้าจอจะตั้งเป็นธีมใด


เปิดมาแล้วทำอะไรได้ทันที
------------------------
ระบบมีข้อมูลโรงเรียนตัวอย่าง (สมมติทั้งหมด) ใส่มาให้พร้อมแล้ว
  ครู 120 คน · ชั้นเรียน 60 ห้อง (ม.1–ม.6) · ห้องสถานที่ 78 ห้อง ใน 5 อาคาร
  รายวิชา 74 วิชา · หลักสูตร 12 ชุด · การมอบหมายสอน 1,011 รายการ
  รวม 1,910 คาบต่อสัปดาห์

กดปุ่ม "จัดตารางอัตโนมัติ" บนหน้าแรกได้เลยโดยไม่ต้องกรอกอะไร
ข้อมูลตัวอย่างใช้ทดสอบการจัดครบทุกคาบได้ โดยเวลาที่ใช้ขึ้นอยู่กับเครื่องและเงื่อนไขที่เลือก


ลำดับการใช้งาน 3 ขั้น
---------------------
ขั้นที่ 1 · เตรียมข้อมูล
  ตั้งค่าโรงเรียน   ตั้งได้ว่าแต่ละวันสอนกี่คาบ พักกลางวันคาบไหน เริ่มกี่โมง
                    วันที่ไม่เท่ากันก็ตั้งต่างกันได้ เช่น วันศุกร์เลิกเร็วกว่าวันอื่น
  ครู               ลงชื่อครู วันที่มาสอน คาบสูงสุดต่อวันและต่อสัปดาห์
  อาคารและห้อง      ลงห้องเรียนพร้อมอาคารและชั้น (ใช้คำนวณระยะเดินระหว่างคาบ)
  ชั้นเรียน          สร้างห้องเรียน เช่น ม.1/1 ถึง ม.6/10
  หลักสูตร          สร้างหลักสูตร "เป็นชุด" เช่น หลักสูตร ม.1 ทั่วไป และ
                    หลักสูตร ม.1 ห้องเรียนพิเศษ EP ใส่รายวิชาและจำนวนชั่วโมงที่สอน
                    แล้วเลือกว่าห้องไหนใช้หลักสูตรชุดนี้ · หนึ่งระดับชั้นมีได้หลายชุด

ขั้นที่ 2 · จัดครูผู้สอน
  เลือกชั้นเรียนทางซ้าย ระบบแสดงวิชาของห้องนั้นเป็นลิสต์ตามหลักสูตร
  แล้วเลือกครูผู้สอน ครูผู้สอนร่วม (คนที่ 2) และห้องที่ใช้สอนของแต่ละวิชา
  ดูภาพรวมการจัดได้ที่หน้าภาพรวม และดูภาระงานครูแบบสดข้างตาราง

ขั้นที่ 3 · เลือกเงื่อนไขแล้วจัด
  เงื่อนไขการจัด    เปิดปิดและกำหนดความสำคัญของแต่ละเงื่อนไขได้เอง เช่น
                    ห้องใกล้กันเดินหากันใกล้ · วิชาไหนควรอยู่ช่วงเช้า ·
                    คาบคู่อยู่ติดกัน · ภาระงานครูกระจาย
  ล็อกคาบ           ปักหมุดวิชาที่จัดครูไว้แล้วให้อยู่วันและคาบที่ต้องการ
                    หรือกันช่องไว้ทำกิจกรรม เช่น หน้าเสาธง ประชุมครู ชุมนุม
  จัดตารางอัตโนมัติ  กดปุ่มเดียว แล้วดูผล แก้ด้วยการลาก และพิมพ์ลงกระดาษ A4


โครงสร้างไฟล์
-------------
schooltable.html          ไฟล์ที่ใช้เปิด
css/app.css               หน้าจอ (โครงสร้างและส่วนประกอบพื้นฐาน)
css/ux.css                ส่วนปรับหน้าจอเพิ่มเติมและการปรับตามขนาดจอ
css/theme.css             ระบบดีไซน์ใหม่ (สี ฟอนต์ เงา รูปทรง) — โหลดเป็นไฟล์สุดท้ายจึงคุมหน้าตาหลัก
css/print.css             เอกสารสำหรับพิมพ์ลงกระดาษ A4 (ขาว–ดำเสมอ ไม่ขึ้นกับธีมหน้าจอ)
js/util.js                เครื่องมือพื้นฐาน หน้าต่างซ้อน ข้อความแจ้งผล
js/store.js               ที่เก็บข้อมูลและการบันทึกลงเครื่อง
js/model.js               ข้อมูลที่คำนวณต่อ การตรวจความพร้อม และระยะเดินระหว่างห้อง
js/mockdata.js            ข้อมูลโรงเรียนตัวอย่าง
js/scheduler.js           เครื่องมือจัดตารางอัตโนมัติ (กฎ H1–H9, S1–S4, เหตุผล R1–R7)
js/xlsx.js                ตัวอ่านไฟล์ .xlsx และ .csv ที่เขียนเอง ไม่ต้องต่ออินเทอร์เน็ต
js/printing.js            ตัวสร้างเอกสารสำหรับพิมพ์
js/components.js          ส่วนประกอบหน้าจอที่ใช้ซ้ำ
js/pages/*.js             หน้าจอทั้ง 16 หน้า
js/app.js                 เมนูและการสลับหน้า
tests/                    ชุดทดสอบที่ใช้ตรวจรับงาน (ไม่จำเป็นต่อการใช้งาน)


ชุดทดสอบ (สำหรับผู้พัฒนา)
-------------------------
ต้องมี Node.js และ Playwright ติดตั้งไว้ แล้วสั่ง

  node tests/engine-test.js     ตรวจเครื่องมือจัดตารางและกฎ H1–H9 ด้วยข้อมูลตัวอย่าง
  node tests/acceptance.js      สถานการณ์ทดสอบครบวงจร Q1–Q6
  node tests/acceptance2.js     ตรวจ Acceptance Criteria หมวด A–O
  node tests/acceptance3.js     ตรวจหน้าภาพรวม เงื่อนไขการจัด และการแบ่งหน้ากระดาษจริง


ข้อจำกัดของเดโมรอบนี้
---------------------
- ข้อมูลเก็บอยู่ในเครื่องผู้ใช้เท่านั้น ไม่มีฐานข้อมูลบนเซิร์ฟเวอร์ และไม่ซิงก์ข้ามเครื่อง
- ใช้งานได้ทีละคน ไม่มีระบบล็อกอินและไม่มีการแจ้งเตือน
- ครูและนักเรียนรับตารางผ่านเอกสารที่พิมพ์เท่านั้น
- เก็บประวัติตารางย้อนหลังได้ประมาณ 10 เวอร์ชัน ตามขีดจำกัดที่เก็บข้อมูลของเบราว์เซอร์
- ข้อมูลตัวอย่างทั้งหมดเป็นชื่อสมมติ ไม่ใช่ชื่อโรงเรียนหรือชื่อบุคคลจริง
